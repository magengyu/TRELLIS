01 / SS VAE：编码器逐层结构

SparseStructureEncoder 使用稠密 3D 卷积，将二值网格映射到对角高斯后验 q(z|S)。虽然名称包含 SparseStructure，网络内部张量仍是稠密张量；“稀疏”描述占据结构，而不是 spconv 运算。

顺序 / 对应模块运算输出形状
输入 S0/1 占据网格[B,1,64,64,64]
input_layerConv3d 1→32，k=3,s=1,p=1[B,32,64,64,64]
blocks：64³ 层ResBlock3d(32) ×2[B,32,64,64,64]
下采样 1Conv3d 32→128，k=2,s=2,p=0[B,128,32,32,32]
blocks：32³ 层ResBlock3d(128) ×2[B,128,32,32,32]
下采样 2Conv3d 128→512，k=2,s=2,p=0[B,512,16,16,16]
blocks：16³ 层ResBlock3d(512) ×2[B,512,16,16,16]
middle_blockResBlock3d(512) ×2[B,512,16,16,16]
out_layerChannelLN → SiLU → Conv3d 512→16[B,16,16,16,16]
chunk(2,dim=1)前 8 通道为 μ，后 8 通道为 log σ²各 [B,8,16,16,16]

后验参数与重参数化

q(z|S) = Normal(μ(S), diag(exp(logvar(S))))
z = μ + exp(0.5 × logvar) ⊙ ε,    ε ~ Normal(0,I)

训练时 sample_posterior=True，通过重参数化采样 z；推理或缓存时默认 False，直接使用 μ。return_raw=True 返回 (z, μ, logvar)，否则只返回 z。Encoder 共 8 个残差块，残差块内部合计 16 个 3×3×3 卷积。

空间分辨率每轴压缩 4 倍：64³→16³。考虑通道后，单个样本从 262,144 个输入标量变为 32,768 个潜标量，是标量数 8 倍压缩；不是按实际字节数定义的文件压缩率。

02 / SS VAE：解码器逐层结构

SparseStructureDecoder 将 8 通道潜变量恢复为一个通道的占据 logits。它是前馈卷积网络，不需要图片条件，也没有编码器到解码器的 U-Net 跳连。

顺序 / 对应模块运算输出形状
输入 z来自 Encoder 或 Flow[B,8,16,16,16]
input_layerConv3d 8→512，k=3,s=1,p=1[B,512,16,16,16]
middle_blockResBlock3d(512) ×2[B,512,16,16,16]
blocks：16³ 层ResBlock3d(512) ×2[B,512,16,16,16]
上采样 1：卷积Conv3d 512→1024，k=3,p=1[B,1024,16,16,16]
上采样 1：重排PixelShuffle3D(r=2)，1024/8=128[B,128,32,32,32]
blocks：32³ 层ResBlock3d(128) ×2[B,128,32,32,32]
上采样 2：卷积Conv3d 128→256，k=3,p=1[B,256,32,32,32]
上采样 2：重排PixelShuffle3D(r=2)，256/8=32[B,32,64,64,64]
blocks：64³ 层ResBlock3d(32) ×2[B,32,64,64,64]
out_layerChannelLN → SiLU → Conv3d 32→1[B,1,64,64,64]

输出是 logits，不是已阈值化的网格

a = Decoder(z)
p(occupied) = sigmoid(a)
S_hat = (a > 0)    等价于    (p > 0.5)

输出头不包含 sigmoid。Dice 损失中再做 sigmoid；BCE 模式直接使用 binary_cross_entropy_with_logits。推理时以零为阈值即可，无需为二值输出额外运行 sigmoid。

Encoder 与 Decoder 必须配套。若更换 VAE，原 Flow 生成的潜变量不一定落在新 Decoder 能正确解释的潜空间中；不能仅凭潜变量形状相同就混用权重。

03 / VAE 基本算子与初始化

预激活残差块 ResBlock3d

F(x) = Conv2(SiLU(Norm2(Conv1(SiLU(Norm1(x))))))
y = F(x) + skip(x)

conv2 的权重和偏置初始化为 0，所以同通道残差块初始化时接近恒等映射。正式配置中的每个残差块两次卷积都使用 k=3、padding=1、stride=1；空间尺寸保持不变。

ChannelLayerNorm32 的归一化维度

先把 [B,C,X,Y,Z] 置换为 [B,X,Y,Z,C]，然后对最后一维 C 做 LayerNorm，再置换回来。每个体素位置单独归一化其通道，既不是对整个三维网格归一化，也不是 BatchNorm。默认带可学习仿射参数，eps=1e-5；归一化计算转为 FP32 后再恢复输入 dtype。

降采样与升采样

算子默认实现尺寸变化
DownsampleBlock3dConv3d(k=2,stride=2)[B,Cin,R,R,R]→[B,Cout,R/2,R/2,R/2]
UpsampleBlock3dConv3d(Cin→8Cout,k=3) + PixelShuffle3D(2)[B,Cin,R,R,R]→[B,Cout,2R,2R,2R]
PixelShuffle3D(r):
[B, C × r³, X, Y, Z] → [B, C, rX, rY, rZ]

PixelShuffle 本身没有参数，只把通道分组重排到空间子体素；用于学习上采样的参数来自前面的卷积。代码还提供 avgpool / nearest 分支，但正式 Encoder / Decoder 使用 conv 分支。

实现细节：norm_type 传给输入/输出头的 norm_layer；当前构造残差块时未向其透传 norm_type，残差块保持默认 layer。若未来要整体切换 GroupNorm，需要同时修改构造逻辑，并检查权重兼容性。

04 / VAE 训练目标与样本语义

VAE 联合更新 Encoder 与 Decoder，不输入照片。数据集提供 S∈{0,1}B×1×64×64×64，训练目标是重建输入网格，同时使后验接近标准正态。

默认 Dice + KL

p = sigmoid(Decoder(z))
L_dice = 1 - (2 × Σ(p ⊙ S) + 1) / (Σp + ΣS + 1)
L_KL = 0.5 × mean(μ² + exp(logvar) - logvar - 1)
L_VAE = L_dice + 0.001 × L_KL

Σ 在当前实现中跨整个 batch 和全部体素求和，末尾 +1 是平滑项。KL 对 batch、潜通道和空间位置求均值。Dice 关注重建占据区域的重叠；KL 约束潜表示的分布。二者的权重与归约方式必须同时考虑，不能只比较公式中的数值系数。

可选 BCE 重建项

L_BCE = mean(BCEWithLogits(a, S))
L_VAE = L_BCE + λ_KL × L_KL
训练设定独立正式配置
优化器AdamW；学习率 1e-4；weight_decay=0
精度FP32 master parameters + bf16 autocast
梯度与 EMA全局梯度范数裁剪 1.0；EMA 衰减 0.9999
batch / 累积batch_size=1；accumulation_steps=1，可调整
步数max_steps=100000；这是当前独立配置，不是原论文训练预算

占据网格需要保持一致的定义

原体素化工具记录与三角网格表面相交的体素，没有执行封闭实体内部填充。自行使用实体占据训练也可行，但目标分布会改变。应统一中心、尺度、坐标轴；若统一正面，则在整个数据集维持同一约定。

Flow 缓存使用 Encoder 的 μ，不对 SS 潜变量额外缩放或标准化。重新训练 Encoder 后应重新缓存；cache_metadata.json 会记录编码器权重 SHA-256。

05 / SS Flow：总体网络结构

SparseStructureFlowModel 是带图片 Cross-Attention 的三维潜空间 Transformer。输入为带噪潜变量 xt、时间 t 和条件序列 c，输出与 xt 同形状的速度场 vθ，不是直接输出 64³ 占据概率。

步骤运算输出形状
输入 x_t潜变量网格[B,8,16,16,16]
patchify，p=1不合并邻域，只重排维度[B,8,16,16,16]
flatten + transposeL=(16/p)³=4096[B,4096,8]
input_layerLinear(8→1024)[B,4096,1024]
加位置编码固定 APE buffer [4096,1024][B,4096,1024]
blocksModulatedTransformerCrossBlock ×24[B,4096,1024]
输出归一化F.layer_norm，末维 1024，无仿射参数[B,4096,1024]
out_layerLinear(1024→8)[B,4096,8]
reshape + unpatchify恢复规则三维网格[B,8,16,16,16]

正式超参数

model_channels=1024；num_heads=16；每头 64 维；num_blocks=24；MLP ratio=4（隐藏维度 4096）；patch_size=1；pe_mode=ape；share_mod=False；自注意力 qk_rms_norm=True，交叉注意力 qk_rms_norm_cross=False。

这不是多尺度 U-Net：所有 24 个块都在相同 16³ 空间尺度上处理序列，没有 Transformer 内部的空间上下采样，也没有跨层 Encoder–Decoder 拼接。

06 / Flow Transformer 块内部

每块依次执行时间调制的 Self-Attention、图片 Cross-Attention、时间调制的 MLP，包含三条残差路径。h 始终为 [B,4096,1024]；c 为 [B,T,1024]；时间嵌入 e 为 [B,1024]。

时间条件产生六组调制向量

[shift_sa, scale_sa, gate_sa, shift_ff, scale_ff, gate_ff]
    = chunk(Linear_1024→6144(SiLU(e)), 6)

每一组形状为 [B,1024]，沿 token 维广播为 [B,1,1024]。share_mod=False 表示各块分别持有调制 MLP，不在 24 层之间共享参数。

三条残差路径的实际顺序

u = LN1(h) × (1 + scale_sa) + shift_sa
h1 = h  + gate_sa × SelfAttention(u)

h2 = h1 + CrossAttention(LN2(h1), c)

w = LN3(h2) × (1 + scale_ff) + shift_ff
h3 = h2 + gate_ff × MLP(w)
组件实现细节
LN1 / LN3elementwise_affine=False，eps=1e-6
LN2elementwise_affine=True，eps=1e-6；共 2048 个仿射参数
MLPLinear 1024→4096 → GELU(approximate=tanh) → Linear 4096→1024
Cross-AttentionQ 来自网格 tokens；K/V 来自图片 tokens；没有额外时间 gate
注意力 Dropout独立 SDPA 调用使用默认 dropout_p=0

初始化与梯度检查点

一般 Linear 用 Xavier uniform，偏置置零；时间 MLP 权重用标准差 0.02 的正态分布。各块调制输出层和整个 Flow 的 out_layer 置零。初始化时自注意力和 MLP gate 为零，但 Cross-Attention 路径未被该 gate 关闭。正式训练启用 use_checkpoint=True，通过重算块前向降低激活保存量。

07 / Self-Attention 与 Cross-Attention

自注意力：建立三维网格位置之间的关系

h: [B,L,1024] → Linear_QKV → [B,L,3,16,64]
Q,K,V: [B,16,L,64]    (L=4096)
Attention(Q,K,V) = softmax(Q Kᵀ / √64) V
拼接各头 → [B,L,1024] → Linear_out

Q、K 经过每头的 MultiHeadRMSNorm，V 不归一化。实现将向量按最后一维做 L2 normalize，再乘 √64 和可学习 γ。γ 的形状为 [16,64]，Q 与 K 各自有一组参数。

Q_norm = normalize_L2(Q.float(), dim=-1) ⊙ γ_Q × √64
K_norm = normalize_L2(K.float(), dim=-1) ⊙ γ_K × √64

交叉注意力：把图片信息注入网格

Q = Linear_Q(h),         h: [B,4096,1024]
K,V = split(Linear_KV(c)), c: [B,T,1024]
Q: [B,16,4096,64]    K,V: [B,16,T,64]

每个三维位置可以查询图片中所有 token，学习可见轮廓、部件和外观线索与目标形状的关系。正式配置未开启交叉注意力的 Q/K RMSNorm。模型没有把某个图片 token 通过已知相机投影，硬性对应到某个三维位置。

项目Self-AttentionCross-Attention
Query 来源网格 tokens网格 tokens
Key / Value 来源同一组网格 tokens图片 tokens
注意力矩阵概念尺寸[B,16,4096,4096][B,16,4096,T]
Q/K RMSNorm开启默认关闭
空间 / 条件联系网格位置之间网格位置与图片之间
独立版本使用 PyTorch SDPA；参数布局与原网络兼容。SDPA 可选高效内核，实际运行不一定显式保存完整注意力矩阵；上表描述数学上的尺寸。

08 / 三维位置编码与时间编码

固定三维正弦位置编码 APE

对 16×16×16 网格构造 meshgrid(indexing=ij)，坐标范围为每轴 0～15，按与潜网格相同的顺序展平成 4096 个位置。位置编码无可训练参数，作为 pos_emb buffer 保存到 state dict。

F = floor(1024 / 3 / 2) = 170
ω_j = 10000^(-j/F),    j=0,...,169
PE_axis(a) = concat(sin(aω), cos(aω))  # 340 维
PE(x,y,z) = concat(PE_axis(x), PE_axis(y), PE_axis(z), 0,0,0,0)

三个轴共产生 1020 维，再补 4 个零得到 1024 维；位置向量在进入第一个 Transformer 块之前相加。当前独立 Flow 仅支持 APE，不能通过切换配置把现有权重直接变成 RoPE 架构。

时间编码 TimestepEmbedder

τ = 1000 × t
ω_j = exp(-log(10000) × j/128),    j=0,...,127
f(τ) = concat(cos(τω), sin(τω))     # [B,256]
e = Linear_1024→1024(SiLU(Linear_256→1024(f(τ))))

训练和推理都先将归一化时间 t∈[0,1] 乘以 1000，再送给模型。若在外部调用 forward 时遗漏该倍率，会改变网络看到的时间条件。时间 MLP 输出 [B,1024]，再由每个块的调制 MLP 产生六组 scale、shift、gate。

patch_size 如何影响 token 数

patch_sizetoken 长度 L每 token 的输入维度
1（正式权重）16³=40968
2（架构可配置）8³=5128×2³=64
改变 patch_size 会改变输入/输出 Linear 权重形状与 pos_emb 尺寸，通常不能严格加载现有权重。扩展分辨率也必须同步检查 VAE、位置编码、训练潜变量和计算开销。

09 / 图片编码与多视角条件

默认外部图片编码器为 dinov2_vitl14_reg。它不属于 555.54M 参数的 SS Flow；独立训练默认读取已缓存图片特征，DINOv2 不参与 Flow 的优化器更新。

前处理与特征提取

  • 已有非全不透明 alpha 时直接使用；否则默认调用 rembg。去背景前先把长边限制到 1024。
  • 以 alpha>0.8×255 的区域确定包围框，围绕中心按较长边扩大约 1.2 倍，裁剪为方形并缩放到 518×518。RGB 与 alpha 相乘，透明区域对应黑色。
  • RGB 归一化到 [0,1]，再按 mean=[0.485,0.456,0.406]、std=[0.229,0.224,0.225] 标准化。
  • 取 DINOv2 的 x_prenorm，随后对最后一维执行无仿射 LayerNorm；不是只取 CLS，也不是只取 patch tokens。
条件维度默认值及来源
图像 patch 网格518/14=37，因此 37²=1369 个 patch tokens
序列长度 T1369 patch + 1 CLS + 4 register = 1374
token 特征维度1024，与 Flow cond_channels 匹配
单视角 / 多视角缓存[1,1374,1024] / [V,1374,1024]

训练视角与推理融合

缓存以一个对象的多个视角为一条记录。训练时数据集每个 epoch 为对象选取一个视角；推理时可轮流引导或逐步平均预测。没有正面/侧面标签、相机内外参、相机位姿估计或显式多视角三角测量。

上表 T=1374 针对默认 DINOv2 版本的前缀 token 约定。外接条件允许可变 T，但同一训练 batch 需要一致 T；更换条件通道 C 必须同步修改网络并重新训练匹配权重。

10 / Flow Matching 的训练定义

训练目标 z 使用配套 VAE Encoder 的后验均值。Flow 不通过二值网格上的重建损失来训练，而是在带噪潜空间回归速度。VAE 与 Flow 在当前工程中分阶段训练，不进行端到端联合更新。

带噪路径与目标速度

ε ~ Normal(0,I)
t = sigmoid(η),  η ~ Normal(mean=1,std=1)
σ_min = 1e-5
x_t = (1-t)z + [σ_min + (1-σ_min)t] ε
v_target = d(x_t)/dt = (1-σ_min)ε - z
L_flow = mean((v_θ(x_t,1000t,c) - v_target)²)

t=1 对应纯标准高斯噪声；t=0 对应 z+σ_min ε。因此这条路径在零时刻仍有极小噪声项，采样实现直接返回积分终点，不额外做解析去噪。不要把这里的时间方向与其他 Flow 实现混用。

Classifier-Free Guidance 的训练准备

m ~ Bernoulli(p_uncond=0.1), 每个样本独立
c_train = 0 if m=1 else c

置零的是整条图片条件序列。这样同一个模型学到有条件与无条件速度，推理时可以组合二者。条件置零不等于传入一张黑色图片：黑色图片经过 DINOv2 仍可能产生非零特征。

11 / Euler 采样、CFG 与多图融合

时间序列与 Euler 更新

u_i = 1 - i/N,    i=0,...,N
t_i = r×u_i / [1+(r-1)u_i],    r=3
x_1 ~ Normal(0,I)
x_(t_next) = x_t - (t - t_next) × v_guided(x_t,t,c)

默认 N=12，从 t=1 向 0 积分；重标定 r=3 改变各阶段的步长分布。Flow 预测潜空间速度，每次只更新同一个潜网格。最后运行一次 VAE Decoder，再以 logits>0 得到 64³ 占据网格。

引导区间与强度的精确定义

t∈[0.5,1]: v_guided = (1+g) v_cond - g v_uncond
其他时间:  v_guided = v_cond
默认 g=7.5；v_uncond 使用全零条件

这里的 g 与有些实现中 v_uncond+w(v_cond-v_uncond) 的 w 相差 1：w=1+g。g=0 仍使用条件预测，并不变为无条件采样。

多视角如何共同约束一个网格

模式每一步的条件预测计算特性
stochastic第 i 步用第 i mod V 张图；实际为确定性轮换每步一张条件图；步数须≥图片数
multidiffusion对同一个 x_t 分别预测各视角速度，再算术平均每步 V 次条件预测，CFG 区间再加一次无条件预测

对于 3 张图和 12 步，轮流模式按 0、1、2 循环，每张图使用 4 次。两种模式都不是先生成多个模型再拼接；也不是将所有视角特征拼成长序列后一次送入网络。随机种子控制初始噪声，轮流模式的视角顺序由输入列表决定。

局限：训练数据提供形状先验，图片条件提供可见线索，但没有显式相机几何约束；多视图冲突、遮挡或外观不一致时，不能保证严格几何对齐。

显存：参数量之外还要计算训练状态与激活

Flow 的 FP32 参数约 2.07 GiB；若同时保存参数、梯度和 Adam 的两个 FP32 动量，仅这四项就约 8.28 GiB。再保存一份 FP32 EMA 参数约增加 2.07 GiB，尚未包含激活、CUDA 工作区、位置 buffer、加载峰值等。混合精度不代表这些 FP32 master 状态全部减半。

这些是布局和状态的数量级估算，不是整机实测峰值。8 GB 显卡可以完成此项目预训练推理，不意味着能训练完整 L 模型。减少宽度/层数/分辨率、关闭 EMA 都会改变成本，其中部分修改也会破坏现有权重的结构兼容性。

三个独立权重的角色

weights/encoder：网格编码与训练缓存；weights/decoder：潜变量解码；weights/denoiser：图片条件速度预测。每个前缀对应一个 .json 和一个 .safetensors。权重加载保留原模型 state-dict 名称；骨干结构兼容，不代表任意组合具有语义兼容性。

迁移和修改的关键检查

  • 改变 VAE 时同步 Encoder、Decoder、潜变量缓存及 Flow；改变图片编码器时检查 token 约定与 cond_channels。
  • 不要将 SS 潜变量与后续 SLAT 潜变量混淆：本文只覆盖 SS 两阶段，未讨论 Mesh、Gaussian 或外观解码。
  • 独立训练采用 AMP、全局范数裁剪与 EMA；未复刻原训练器的全部分布式与自适应裁剪策略。网络架构兼容不等于复现原训练收敛结果。
