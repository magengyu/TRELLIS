# 占据网格 Web 工作台

## 启动

在项目根目录运行：

```bash
cd /你的项目/ss_module
python webapp/app.py
```

浏览器访问 **http://127.0.0.1:7860**。也可以从任意目录通过脚本绝对路径启动。

当前虚拟环境已有 Flask、Plotly。其他环境需要先安装独立包及图片依赖，再安装界面依赖：

```bash
python -m pip install -e '.[image,web]'
```

修改监听地址或端口：

```bash
python webapp/app.py --host 0.0.0.0 --port 7860
```

服务面向本机或可信局域网使用，没有登录机制，不应直接暴露到公网。前端脚本和 Plotly 均由本地服务提供，无需访问 CDN；首次加载 DINOv2 可能需要联网下载权重。

## 操作

1. 点击或拖入图片，支持追加、单张移除及清空。多图应为同一物体的不同视角。
2. 调整步数、随机种子、引导强度和多图融合模式，点击“生成占据网格”。
3. 生成后拖动旋转、滚轮缩放、右键平移；默认同时显示体素中心点和立方体边线，可分别开关，并重置视角。
4. 点击“下载 NPZ”保存完整 `64³` 网格、占据坐标及原始 logits。

上传限制：1～12 张，总计不超过 32 MB，每张不超过 2500 万像素。轮流引导模式下，步数必须不少于图片数；逐步平均模式每一步使用全部视角，计算量较大。

## 模型与输出

- 默认加载 `ss_module/weights/` 的独立 Sparse Structure Flow 和 VAE Decoder，以及 DINOv2 图像编码器。可以用 `SS_WEIGHTS` 和 `SS_DECODER_WEIGHTS` 环境变量指定自训练权重目录。
- 首次生成加载模型，后续请求复用模型。每次只运行一个任务，其他生成请求返回忙碌提示。
- 不运行 SLAT 和后续外观生成阶段。
- 每个占据体素显示一个中心点和立方体的 12 条边线，相邻体素共享的边线只绘制一次；中心点和边线可分别开关，不绘制实体面。
- 结果保存在 `ss_module/webapp/outputs/<任务ID>/`，包括 `occupancy.npz` 与 `preview.json`。上传原图仅在内存中处理。
- NPZ 的 `occupancy` 为 `[64,64,64]` bool 网格，`coords` 为 `[N,3]` int32 索引，`logits` 为 `[64,64,64]` float32 原始输出。空间中的体素中心为 `(coords + 0.5) / 64 - 0.5`。
- 生成状态保存在服务内存中，重启后不会恢复历史任务入口；已生成的文件仍在磁盘上。输出不会自动删除，可在停止服务后按需清理。
- 状态会显示当前采样步数；终端记录具体错误。
